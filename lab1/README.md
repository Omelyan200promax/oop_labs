# Лабораторная работа №1: Основы ООП (Множества и Мультимножества)

Данный репозиторий содержит выполнение Лабораторной работы №1 по курсу «Проектирование программного обеспечения интеллектуальных систем» (ППОИС). 
В качестве предметной области выбрана **Теория множеств (Вариант 1.4)**.

## 📌 Реализованный функционал
В рамках работы реализованы классы для работы с неориентированными канторовскими множествами и мультимножествами:
* **`Atom`** — простой (неделимый) элемент множества.
* **`Set`** — неориентированное канторовское множество (элементы не повторяются, могут быть вложенными).
* **`MultiSet`** — неориентированное мультимножество (элементы могут повторяться, учитывается кратность).
* **`SetElement`** и **`SetLike`** — абстрактные интерфейсы для обеспечения полиморфизма и единого взаимодействия.

Реализованы все требуемые операции: объединение (`+`), пересечение (`*`), разность (`-`), проверка принадлежности (`[]`), вычисление мощности, построение булеана (множества всех подмножеств), парсинг из строки и перегрузка операторов ввода/вывода (`<<`, `>>`).

## 🛠️ Технологии и архитектура
* **Язык:** C++17
* **Система сборки:** CMake (без привязки к IDE)
* **Тестирование:** GoogleTest (покрытие кода **> 90%**)
* **Документация:** Doxygen
* **CI/CD:** GitHub Actions (сборка, тесты, проверка покрытия, статический анализ `cppcheck`, релиз артефактов)
* **Паттерн:** Разделение логики предметной области (`src/`), интерфейсов (`include/`) и консольного интерфейса (`app/`).
