lab2 — Книжный склад (ООП, C++17)

Сборка и запуск

cmake -S . -B build
cmake --build build
./build/lab2_cli # консольное меню
./build/lab2_tests # тесты

Структура

  • include/lab2/, src/ — библиотека классов: core, common, people, orders, warehouse, exceptions.
  • app/ — консольное меню:
    • menu.cpp — данные, главное меню, каталог;
    • menu_customer.cpp — кабинет клиента (заказ, оплата, отмена, возврат, отзывы, уведомления);
    • menu_staff.cpp — кабинеты сотрудников (действия зависят от класса сотрудника и уровня доступа);
    • menu_warehouse.cpp — структура склада, инвентаризация, оборудование, метрики;
    • menu_utils.cpp — безопасный ввод и вывод UTF-8.

Жизненный цикл заказа

Создан → Оплачен (клиент) → Отгружен (кладовщик) → В доставке → Доставлен (курьер) → при необходимости Возвращён (менеджер одобряет запрос клиента).
