Подробное описание

Заказ клиента на одну или несколько книг.

Статус хранится строкой: Created (создан), Paid (оплачен), Shipped (отгружен), In Delivery (в доставке), Delivered (доставлен), Cancelled (отменён), Returned (возвращён). Новый заказ получает статус Created.
